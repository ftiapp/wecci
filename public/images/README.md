## เพิ่มรูปใหม่

1. วางไฟล์ในโฟลเดอร์ของหน้านั้น (ถ้าใช้หลายหน้าให้ไว้ `shared/`)
2. ใส่พาธเต็มในไฟล์ข้อมูลตามตารางด้านบน เช่น `/images/hero/xxx.png`
3. ตั้งชื่อไฟล์เป็นภาษาอังกฤษตัวเล็ก คั่นด้วยขีด **ห้ามมีเว้นวรรคหรือวงเล็บ**

## ขนาดแนะนำ

- แบนเนอร์ (hero, page): 2400 × 1200 px
- ภาพในเมกะเมนู: 800 × 500 px (16:10)
- รูปบุคคล: 600 × 600 px (สี่เหลี่ยมจัตุรัส)
- แปลงเป็น `.webp` ก่อนขึ้น git จะลดขนาดได้ราว 80–90%
